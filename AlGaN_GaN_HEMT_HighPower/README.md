# AlGaN/GaN HEMT High-Power TCAD Simulation

## Overview
TCAD simulation of AlGaN/GaN high electron mobility transistor (HEMT) 
on SiC substrate with 2DEG channel for high-power applications.

## Quick Start
1. See `project_description.md` for full technical details
2. View plots in `results/plots/`
3. Review code in `silvaco_code/AlGaN_GaN_HEMT.in`

## Key Features
- Gate voltage sweep: -3V to +3V
- Drain voltage: 0-30V (high power capability)
- Temperature range: 300K-1000K
- Polarization effects modeling
- 2DEG channel optimization
- SiC substrate integration

## Key Results
- 2DEG Density: High electron concentration
- Polarization Charge: Significant at interfaces
- Thermal Stability: Validated to 1000K
- On-State Current: High current drive
